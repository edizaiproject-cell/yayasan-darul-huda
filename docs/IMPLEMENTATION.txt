ERROR YANG DIPERBAIKI
1. Ukuran hasil ikon tidak sesuai manifest: generator diubah memakai kanvas dengan ukuran pasti.
2. Aset 404 pada produksi Windows: cache statis Vinext memakai pemisah path Windows; scripts/start.mjs memakai static handler filesystem Vinext pada allowlist aset.
3. Unggahan baru tidak ada di folder hasil build: route /uploads/{file} mengambil media publik runtime dari penyimpanan aktual.
4. Hot reload CommonJS pada library server: sharp dan sanitize-html ditetapkan sebagai serverExternalPackages.
5. Header admin produksi tidak memuat no-store: dipastikan di skrip server selain konfigurasi route.
6. Status khusus donasi berpotensi dipakai pada modul berita: setiap modul kini mempunyai allowlist status, dengan pengujian anti-bypass permission publikasi.

CARA MENJALANKAN DAN DEPLOYMENT
Development: npm run dev.
Produksi: npm run build lalu npm start.
Setup awal: npm ci, salin .env.example ke .env, npm run assets, npm run setup.
Buka http://localhost:5174/admin, akun admin@darulhuda.local, password development diberikan dalam percakapan. Password awal wajib diganti sebelum mengelola build produksi.
Deployment yang sesuai: satu server Node 24 dengan disk persisten, reverse proxy HTTPS, backup SQLite/unggahan, SITE_URL domain resmi. Multi-instance memerlukan database/media bersama. Panduan lengkap dan daftar route/API: README.md.
